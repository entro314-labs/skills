# Logo Construction

## Process

1. State the single concept in one sentence (the "one memorable thing").
2. Choose the base primitive from the concept (see Base shapes below). Start from circle, square, triangle, intersecting lines or spiral.
3. Construct on a grid: modular 8x8 / 16x16, or golden ratio 1 : 1.618. Every dimension should relate to another by a shared ratio.
4. Subtract: remove every part that does not carry the concept.
5. Re-test recognizability: solid black, 16px, white-on-dark, one brand color.
6. Only then add color (primary, optional secondary).

## Complexity budget

Practical rule: more than about 3 visual elements means simplify. The mark should be roughly as simple as a child could draw, while still carrying the concept.

## Distinctiveness tests

- Child test: can a child draw it from memory?
- Sentence test: can it be described in one sentence?
- Silhouette test: is it recognizable filled solid, with no interior detail?
- Shape-language test: one shape language only (all round, or all angular, or one deliberate contrast). Mixing many shape languages reads as incoherent.

## Anti-patterns

| Anti-pattern | Fix |
| --- | --- |
| Literal depiction of the trade (fork, tooth) | Abstract the idea (rhythm, structure, outcome) |
| Drop shadows, gradients, 3D, bevels in the primary mark | Flat solid fills; effects only in presentation |
| Shape chosen for looks with no concept link | Tie each shape to the concept or remove it |
| Many unrelated shape languages | Pick one family |
| Icon needs color to be understood | Rework until it reads in black |
| Detail lost at 16px | Thicken strokes, merge or delete small parts |

## Emoji or reference to icon

Abstract rather than copy: palette = circle + 3 dots; lightning = angular zigzag; target = concentric circles; gem = faceted polygon; rocket = triangle with accent.

## Industry pattern shorthand (starting points only)

| Sector | Icon | Wordmark | Color |
| --- | --- | --- | --- |
| Tech / SaaS | Geometric | Sans | One accent plus black, generous whitespace |
| Enterprise | Square / rectangle based | Neutral sans | Blue / gray |
| Consumer | Rounded forms | Humanist sans | Warmer palette, slightly tighter spacing |

## Square container procedure

1. Compute glyph bounds. Take the larger side as S.
2. Create a square artboard sized S plus padding (10% safe area per side is a good default).
3. Center the glyph optically in the square (not just by bounding box: triangles and dense shapes need a nudge).
4. Never scale x and y independently.

## Base shapes

| Shape | Conveys | Typical fit |
|---|---|---|
| Circle | wholeness, containment, continuity, community | collectives, non-profits, wellness, global orgs |
| Cross / line | connection, intersection, balance | healthcare, partnerships, navigation |
| Triangle | direction, stability, aspiration, change | tech, automotive, aerospace, performance |
| Square / rectangle | stability, reliability, structure | finance, enterprise, legal, institutions |
| Spiral | growth, evolution, creativity | creative agencies, growth companies |

Treat meanings as starting associations; the concept must still tie to the specific brand. Triangle orientation: up = aspiration, stability; down = focus, precision; left = return, history; right = forward, progress.

## Compound icons

Combine at most 2-3 base shapes with a geometric relationship (shared centers, tangents, equal radii, ratio-based offsets), never random placement.

| Pairing | Reading |
|---|---|
| circle + triangle | unity with direction |
| circle + line | connection within a whole |
| square + circle | structure meets flow |
| triangle + square | dynamic stability |
| multiple circles | community |

Construction methods: golden-ratio spacing (1 : 1.618); circle packing (circles of related sizes touching or nesting); geometric subdivision (one shape split into meaningful parts, negative-space cuts).

## Grids

| Grid | Use |
|---|---|
| Circular (concentric circles) | radial balance, round marks |
| Modular (equal modules) | blocky or stencil marks |
| Golden (1 : 1.618) | proportion-driven compositions |

The grid is a construction aid; verify optically afterwards. Geometry that does not simplify when reduced, or arbitrary shape combinations, is a sign the construction is wrong.

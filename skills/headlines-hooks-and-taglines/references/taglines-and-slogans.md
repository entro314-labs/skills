# Taglines and slogans

## Trueline vs tagline vs mantra

| Item | Audience | Purpose |
|---|---|---|
| Trueline | Internal | Compass for decisions; write first |
| Brand mantra | Internal | ~3 words: [emotional modifier] + [descriptive modifier] + [brand function]; not a tagline |
| Tagline / slogan | Public | Memorable expression of the position; written after the trueline |

Position before tagline. A tagline cannot rescue unclear positioning.

## Seven-step process

1. Internal brand audit: purpose, values, personality, differentiator.
2. Competitor tagline audit: list shared words and clichés to avoid.
3. Audience research: language they use, what they want, awareness level.
4. Brainstorm 100+ raw options (slogan-only work: 10-15 across six angles).
5. Distill.
6. Shortlist 5-7 with objective feedback from people outside the team.
7. Test: A/B or panel, trademark conflicts (verify separately), different media and languages.

## Distillation

1. Write the USP in full sentences.
2. Cut the word count in half; repeat twice more.
3. Apply one linguistic device: rhyme, alliteration, parallelism, rhythm, sensory language.
4. Stop when removing another word harms clarity.

## Types

| Type | Idea |
|---|---|
| Descriptive | Says what it is or does |
| Emotional | Evokes a feeling |
| Aspirational | Promises who you become |
| Imperative | Command to act |
| Superlative | Claims best/only (must be defensible) |
| Interrogative | Asks a question the brand answers |
| Provocative | Challenges a norm |

Formulas: Verb + Noun; Action + Benefit; Empowering word + X ("Imagine X"); The only/best X that Y.

## Slogan angles (2-3 options each, 10-15 total)

Benefit-focused, emotional, clever wordplay, aspirational, problem-solution, brand promise.

## Length, sound, clarity

- 2-7 words; ideal 3-5; never above 8.
- Alliteration and rhythm help recall; rhyme only when natural.
- Likability is not memorability: easily liked lines are often forgettable. Memorable lines use uncommon words, concrete imagery or slight complexity.
- Emotional triggers: identity, aspiration, self-worth, sensory experience.
- No jargon. Drop cleverness that blurs meaning. If you confuse, you lose.
- A deliberate grammar break can be memorable, but treat it as a risk, not a rule.
- Keep the brand name out of the tagline so the line works alone and survives a rename.

## Audience awareness mapping

| Awareness | Approach |
|---|---|
| Most aware | Direct product message |
| Product-aware | Benefit |
| Solution-aware | Differentiation |
| Problem-aware | Problem, then solution |
| Unaware | Identity or aspiration |

## Tests

| Test | Pass condition |
|---|---|
| Onlyness | "Our [offering] is the only [category] that [benefit]." Fails if a competitor's name fits the sentence |
| ABC | Authentic, Believable, Customer-oriented |
| AIDA | Grabs attention, sustains interest, creates desire, prompts action |
| No-context reader | Someone unfamiliar with the brand states the meaning correctly |
| Uniqueness search | Existing slogans searched; no competitor could use it |
| Unintended meaning | Checked for double meanings and negative connotations |
| Translation | Tested with native speakers in each target market |
| Medium limits | Legible on a billboard and a business card |
| Evaluation axes | Memorability, clarity, emotional response, brand fit, differentiation |

Trademark availability is outside this method and needs separate legal verification.

## Common mistakes

| Mistake | Fix |
|---|---|
| Too generic | Onlyness test |
| Jargon | Everyday words |
| Features without benefit | Ask "so what?" |
| Overcomplicated | Distill |
| Overly clever | Be direct |
| Copying | Onlyness test, existing-slogan search |
| Mistranslation | Test in target markets |
| Off-brand | Align with trueline |
| Medium limits ignored | Test on small and large formats |
| No testing | A/B or panel |
| Brand name inside tagline | Keep separate |

# Headline formulas

Placeholders in [brackets]. All figures in examples are illustrative; replace with real data.

## Element pairing map

Extract six elements from the content: Problem, Goal, Benefit, Concept, Example, Process. Pair two, write the line, keep the 2-3 best of 5-10 pairings.

| Pairing | Template |
|---|---|
| Problem + Process | How to [solve problem] in [N steps] |
| Benefit + Timeframe | [Benefit] in [time] |
| Concept + Audience | [Concept] for [specific people] |
| Goal + Benefit | [Goal] to [benefit] |
| Example + Process | [Result] using [method] |
| Problem + Benefit | Stop [problem] and start [benefit] |

## Formula set

| Formula | Template |
|---|---|
| How-to | How to [result] in [timeframe] |
| List | [N] Ways to [goal] |
| Question | Are you making these [N] [topic] mistakes? |
| Curiosity gap | The surprising truth about [topic] |
| Benefit-driven | [Do this] to [get benefit] |
| Authority secret | [Expert]'s secret to [result] |
| Without | Do [great thing] without [thing they hate] |
| Quick and easy | A quick and easy way to [solve problem] |
| Name your reader | [Reader type]: [topic] |
| Essential knowledge | [N] tools every [profession] should know |
| Time-saving | I tested [N]+ [things]. Save [time] with these top picks |
| Craft | The art of [topic] |
| Anti-list | [N] ways to ruin [topic] |

Low-credibility pattern: "1 weird trick for [result]". Use sparingly; it reads as spam in most channels.

## Writing rules for headlines

- Make it a complete ad in itself: a reader who sees only the headline should get the promise.
- Include a specific number where truthful; odd or precise numbers read as more credible than round ones.
- Plain language; no puns or literary allusions; news value ("new", "now", a fresh angle) when true.
- 6-12 words as a working range.
- Name the audience when the segment is narrow ("for freelance designers").
- Keep one structure; do not stack two formulas.

## Quick diagnostics

| Symptom | Fix |
|---|---|
| Reads like a topic label | Add a result and a number |
| Process before payoff | Lead with benefit |
| Could appear on any competitor's page | Add a specific, ownable detail |
| Reader must know context | Rewrite to stand alone |

# Hooks

A hook earns the next sentence. Social hooks: max 3 sentences, first sentence short, every sentence pulls the reader to the next. Pick one type per hook.

## Hook types

| Type | Pattern | Notes |
|---|---|---|
| Curiosity | State what and why, omit how; or give start and end, omit the middle; or make a bold claim without proof (yet) | The payoff must exist and be delivered |
| Transformation | [Before] -> [after]. Here's how: | Needs a believable before/after |
| Authority | [Credentials or results]. Here's what [audience] should know: | Credentials must be real and relevant |
| Problem callout | Are you making these [N] [topic] mistakes? | Loss framing; name the cost |
| Target callout | [Audience]... [insight they need] | Name the reader so the right people stop |
| Bold claim | [Surprising claim]. Here's why: | Claim must be defensible in the body |

## Sticky devices

Add one, stack at most two.

| Device | Example shape |
|---|---|
| Alliteration | repeated opening sounds in key words |
| Symmetry | "Read for awareness. Write for understanding." |
| Contrast | opposing ideas in one line (less vs more, before vs after) |
| Rhythm | short-short-long cadence |
| Rhyme | only when natural; forced rhyme reads as jingle |

## Building a hook from the story

1. Reduce the content to Problem + Goal + Path.
2. Pick the hook type that fits the strongest element (problem -> callout, result -> transformation, expertise -> authority).
3. Write 10+ variants across at least 3 types.
4. Cut hedges, add one specific number or named audience.
5. Check the first sentence is short enough to read at a glance, and that sentence 2 is a natural next step.
6. Score (see `scoring-and-selection.md`).

## Hook pitfalls

- Hook promises more than the body delivers.
- Abstract opener ("boost productivity"): replace with a picturable outcome.
- Two hook types fighting in one line.
- Hedged opener ("might help you maybe").
- Dense formatting; keep clean visual layout with line breaks.

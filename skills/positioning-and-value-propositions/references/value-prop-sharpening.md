# Sharpening a value proposition

Rewrite the existing value prop from three angles, each in 1-2 sentences.

| Angle | Answer | Name explicitly |
|---|---|---|
| Emotional | Which fear is removed, which desire met, what relief given | The key emotion (fear, desire, relief, joy) |
| Logical | Measurable outcome; time, money or effort saved; a specific number | The key metric |
| Status | How others will perceive the user; identity conferred; group they join | The identity signal |

## Evolution

- Version 1: emotional.
- Version 2: add logical proof.
- Version 3: add status signal.
Record what each step added.

## Final statement

One sentence, maximum 15 words, combining hook, proof and status. Count the words and print as X/15. Use `[X]` for any number you do not have real data for.

Derived outputs:
- Headline: shortened version.
- Tagline: 3-5 words.
- Elevator opener: one spoken sentence.

## One statement per segment

Write a separate statement for each target segment or use case, 2-3 sentences each. Each names:
1. The segment.
2. The primary benefit and outcome.
3. The features that make it possible.
4. Language that audience actually uses.

Useful inputs: existing value prop, segment pain points, features and differentiators, channels (marketing, sales, onboarding), brand tone.

## Touchpoint specs

| Touchpoint | Spec |
|---|---|
| Search ad | Short headline and description within the network's current limits (see `copywriting-ad-copywriting`) |
| Homepage hero | One headline, one subheadline, one CTA; you have about 5-7 seconds |
| Cold email | Subject is a pain or curiosity hook |
| Sales pitch | Problem -> Solution -> Differentiation -> Proof, about 30 seconds |
| Onboarding | Welcome message (set expectations) -> first action (quick win) -> aha moment (first experience of core value) |

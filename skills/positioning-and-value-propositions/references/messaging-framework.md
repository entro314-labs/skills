# Messaging framework (phased build)

Prerequisite: positioning exists. If not, stop and build it first. If personas are unclear, stop and define them. If proof is missing, document gaps and make no claims. If voice guidelines conflict, align them first.

## Phase 1: Foundation

- Positioning recap (statement, one-liner).
- 3 messaging pillars:

| Pillar | Positioning basis | Messaging theme |
|---|---|---|

- Voice and tone: attributes, plus words to use and words to avoid. Define in writing.

## Phase 2: Value propositions

- Primary VP: one sentence, plus a one-paragraph expansion.
- Supporting VPs:

| Claim | Benefit | Evidence |
|---|---|---|

- One VP per persona (typically primary buyer, economic buyer, technical evaluator): pain -> value prop -> key message.

## Phase 3: Proof points

Proof types, each marked AVAILABLE or NEEDED: customer result (testimonials, quantified case studies), third-party validation (awards, certifications, media coverage), technical proof (performance metrics, security certifications), social proof (usage statistics, partnerships).

| Claim | Proof | Source | Status |
|---|---|---|---|

Proof-gap table: gap | plan to obtain. Prioritize by which objections come up most. A claim without proof damages credibility.

## Phase 4: Framework

- 30-second pitch (Problem -> Solution -> Differentiation -> Proof).
- Boilerplate at 25, 50 and 100 words.
- Key messages: 3 supporting points each.
- Objection table:

| Objection | Response | Proof |
|---|---|---|

- Competitor response table: alternative | their pitch | our response.

## Phase 5: Channel adaptation

| Channel | Deliverables |
|---|---|
| Website | Homepage headline, subhead, product headline, CTA |
| Email | Subject line templates, opening line |
| Social | Tone and a sample per platform |
| Sales | One-liner, 3 discovery questions |
| Ads | 3 headline options, body direction |

## Objection handling

Categories, response sequence and price reframe: `SKILL.md`. Put the results in the Phase 4 objection table.

## Messaging-summary output checklist

A messaging summary document should contain: positioning statement; one-liner; pillars; voice and tone; primary and per-persona value props; proof matrix with gaps; boilerplates; objection table; competitor responses; channel adaptations; open questions and assumptions.

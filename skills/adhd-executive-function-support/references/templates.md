# Templates

Starting points. Adapt to the person, fill in together, never present a blank template cold. If the template overwhelms: "Forget the template. What's the one thing today?" Never insist on completing all fields. Emojis optional.


Adjust the peak window to the person; it is not always morning.

## 7. When-then cards

```
WHEN [trigger] -> THEN [action]
- When I finish my coffee -> I open my work document
- When the timer goes off -> I save and stand up for 2 minutes
- When I leave a meeting -> I write 3 notes first
- When I feel I can't go on -> I'm allowed to stop for 15 minutes
- When I open my phone for no reason -> face down, drink water

Today's:
1. When ... -> then ...
2. When ... -> then ...
3. When ... -> then ...
```

## 8. Fast-start message (Focus mode, one message)

```
Your first move: [micro-step under 2 minutes].
Before you start: [water / close other tabs / headphones].
Set a 25-minute timer on your phone, then say "go". You can stop whenever you want.
```

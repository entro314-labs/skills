# Repurposing, Batching and Series

## Repurposing map

| From | To | How |
|---|---|---|
| Newsletter issue | Short post on a professional network | lift the main insight; new hook; link back |
| Blog post | Thread (5-8 posts) | one key point per post; first post carries the hook |
| Long blog post | Two shorter pieces | split on the natural seam; each stands alone |
| Video script | Blog post | light reformat: headings, remove spoken filler |
| Newsletter | Blog post | add headers, title/description metadata, internal links |

Rules:
- Re-cut for the target channel's norms and length; do not paste across.
- Always link or refer back to the original.
- Candidate selection: published within the last 60 days (default window) and, from the quarterly audit, top performers not yet repurposed.
- Stagger repurposed pieces across days so one idea does not flood a single channel.
- A repurposed piece is a pipeline row of its own (its own stage, due date, channel).

### Queue (`repurpose/queue.md`)

| Original | Original Channel | Repurpose As | Target Channel | Status |
|---|---|---|---|---|

Status values: idea / drafting / scheduled / published / dropped.

Create all follow-up rows when the long-form piece enters Draft so they cannot be forgotten.

### Launch sequence for a major long-form piece

| Day | Action |
|---|---|
| 0 | publish original |
| 1 | short post with the main insight, linking back |
| 2 | thread or post expanding 3 key points |
| 5 | mention in the newsletter |
| 14 | check for a Part 2 angle (reader questions, what the piece left out) |

## Batching

Group similar formats into one block to save context-switching cost. Example blocks (tune to your speed):

- all short social posts: one ~45 minute session
- one long-form piece: a ~2 hour uninterrupted block
- 2-3 threads: ~30 minutes

Before a batch:
1. Pull the top backlog ideas ranked by effort vs. impact and relevance.
2. Check topic-cluster balance for the coming weeks.
3. Check the archive to avoid repeating a recent topic.
4. Open the format template.

Keep one template per format, e.g. professional-network post: Hook, Setup, 3 key points, Close, CTA. Improve the template when a piece performs well; do not start from a blank page.

After a batch, move every piece to Scheduled (not left in Draft) and set due dates, so the batch converts into buffer.

## Series

- Define the arc up front: number of episodes and topic per episode.
- Give every series an end point; open-ended series tend to be abandoned.
- Cross-link episodes ("Missed Part 1?") in each installment.
- Draft 1-2 episodes ahead of publishing so a missed week does not break the run.
- If a series misses two consecutive slots, pause it explicitly (Status: paused) and log it in the debt log instead of letting it lapse.

Series tracking table: `pipeline-and-file-formats.md`, "Active Series". Topic-cluster shares and the rolling 4-week balance check: same file, "Topic Clusters", and `weekly-brief-and-gap-detection.md`.

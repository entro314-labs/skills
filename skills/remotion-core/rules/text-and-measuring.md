# Text: animation, highlights and measuring

## Typewriter

Reduce the string by slicing it based on the frame. Always use string slicing; never per-character opacity. Blink the cursor with a frame-based modulo, which is deterministic.

```tsx
const text = 'Welcome to Remotion';
const charsShown = Math.round(
  interpolate(frame, [0, 3 * fps], [0, text.length], {extrapolateRight: 'clamp'}),
);

<h1 style={{fontFamily: 'monospace', fontSize: 60}}>
  {text.slice(0, charsShown)}
  <span style={{opacity: frame % 30 < 15 ? 1 : 0}}>|</span>
</h1>;
```

A fuller example with a blinking cursor and a pause after the first sentence: [assets/text-animations-typewriter.tsx](assets/text-animations-typewriter.tsx) (it uses a system `sans-serif` for brevity; load a font as in [fonts.md](fonts.md) in real work).

## Staggered words

```tsx
{words.map((word, i) => (
  <span
    key={word}
    style={{
      display: 'inline-block',
      marginRight: 20,
      opacity: interpolate(frame, [i * 15, i * 15 + 20], [0, 1], {
        extrapolateLeft: 'clamp',
        extrapolateRight: 'clamp',
      }),
      translate: interpolate(frame, [i * 15, i * 15 + 20], ['0px 30px', '0px 0px'], {
        extrapolateLeft: 'clamp',
        extrapolateRight: 'clamp',
      }),
    }}
  >
    {word}
  </span>
))}
```

Spans generated by a data `.map()` are one template, not individually Studio-editable; the inline-keyframe rule applies to hand-written nodes. Arabic and other joined scripts must be animated per word, not per letter: [arabic-rtl-text.md](arabic-rtl-text.md).

## Hand-drawn annotations with @remotion/rough-notation

For highlights (marker), circles, underlines, strike-throughs, crossed-off text, boxes and brackets. Docs: https://www.remotion.dev/docs/text-highlights. Install `npx remotion add @remotion/rough-notation`, then pick the component that describes the annotation (`<Highlight>`, `<Circle>`, `<Underline>`, `<StrikeThrough>`, `<CrossedOff>`, `<Box>`, `<Bracket>`); the component decides the style and whether it renders behind or on top of the text. Drive `progress` (0 to 1) from the frame, inline, so it is deterministic and Studio-editable:

```tsx
import {Circle, Highlight} from '@remotion/rough-notation';
import {interpolate, useCurrentFrame} from 'remotion';

export const TextAnnotations: React.FC = () => {
  const frame = useCurrentFrame();

  return (
    <div style={{fontSize: 80}}>
      This is{' '}
      <Highlight
        color="rgba(255, 236, 79, 0.62)"
        progress={interpolate(frame, [15, 40], [0, 1], {
          extrapolateLeft: 'clamp',
          extrapolateRight: 'clamp',
        })}
      >
        important
      </Highlight>
      , and this is{' '}
      <Circle
        color="#2563eb"
        progress={interpolate(frame, [15, 40], [0, 1], {
          extrapolateLeft: 'clamp',
          extrapolateRight: 'clamp',
        })}
      >
        connected
      </Circle>
      .
    </div>
  );
};
```

## Measuring text with @remotion/layout-utils

Install: `npx remotion add @remotion/layout-utils`. Measure only after the font is loaded ([fonts.md](fonts.md)).

```tsx
import {fillTextBox, fitText, measureText} from '@remotion/layout-utils';

// Width and height of a text (results are cached)
const {width, height} = measureText({text: 'Hello World', fontFamily: 'Arial', fontSize: 32, fontWeight: 'bold'});

// Largest font size that fits a width
const {fontSize} = fitText({text: 'Hello World', withinWidth: 600, fontFamily: 'Inter', fontWeight: 'bold'});
// ...then cap it: fontSize: Math.min(fontSize, 80)

// Does text exceed a box?
const box = fillTextBox({maxBoxWidth: 400, maxLines: 3});
for (const word of ['Hello', 'World', 'This', 'is', 'a', 'test']) {
  const {exceedsBox} = box.add({text: word + ' ', fontFamily: 'Arial', fontSize: 24});
  if (exceedsBox) break; // would overflow, handle accordingly
}
```

Rules:

- Load fonts first (`waitUntilDone()` from `@remotion/google-fonts`), and pass `validateFontIsLoaded: true` to `measureText()` to throw if the font is not loaded.
- Use identical font properties (`fontFamily`, `fontSize`, `fontWeight`, `letterSpacing`) for measurement and rendering; share one style object.
- Avoid padding and border on the measured element; use `outline` instead of `border` to avoid layout differences.

## Measuring DOM nodes

Remotion applies a `scale()` transform to the video container, so `getBoundingClientRect()` returns scaled values. Divide by `useCurrentScale()`:

```tsx
import {useCurrentScale} from 'remotion';
import {useEffect, useRef, useState} from 'react';

export const MyComponent = () => {
  const ref = useRef<HTMLDivElement>(null);
  const scale = useCurrentScale();
  const [dimensions, setDimensions] = useState({width: 0, height: 0});

  useEffect(() => {
    if (!ref.current) return;
    const rect = ref.current.getBoundingClientRect();
    setDimensions({width: rect.width / scale, height: rect.height / scale});
  }, [scale]);

  return <div ref={ref}>Content to measure</div>;
};
```

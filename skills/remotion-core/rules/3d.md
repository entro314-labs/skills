# 3D with Three.js and React Three Fiber

Follow React Three Fiber and Three.js best practices; only the Remotion-specific rules below differ. Install: `npx remotion add @remotion/three`.

## Wrap content in ThreeCanvas with lighting and an explicit size

`<ThreeCanvas>` from `@remotion/three` is required, must have `width` and `height` props, and the scene needs lighting.

```tsx
import {ThreeCanvas} from '@remotion/three';
import {useVideoConfig} from 'remotion';

const {width, height} = useVideoConfig();

<ThreeCanvas width={width} height={height}>
  <ambientLight intensity={0.4} />
  <directionalLight position={[5, 5, 5]} intensity={0.8} />
  <mesh>
    <sphereGeometry args={[1, 32, 32]} />
    <meshStandardMaterial color="red" />
  </mesh>
</ThreeCanvas>;
```

## Drive every animation from useCurrentFrame()

Shaders, models and anything else must not animate on their own clock, otherwise rendering flickers. `useFrame()` from `@react-three/fiber` is forbidden.

```tsx
const frame = useCurrentFrame();
const rotationY = frame * 0.02;

<mesh rotation={[0, rotationY, 0]}>
  <boxGeometry args={[2, 2, 2]} />
  <meshStandardMaterial color="#4a9eff" />
</mesh>;
```

## Sequence inside ThreeCanvas

Any `<Sequence>` inside a `<ThreeCanvas>` must use `layout="none"`.

```tsx
<ThreeCanvas width={width} height={height}>
  <Sequence layout="none">
    <mesh>
      <boxGeometry args={[2, 2, 2]} />
      <meshStandardMaterial color="#4a9eff" />
    </mesh>
  </Sequence>
</ThreeCanvas>
```

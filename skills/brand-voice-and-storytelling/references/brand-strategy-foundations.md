# Brand Strategy Foundations

Voice should follow strategy. If these are undefined, define them before writing a voice guide.

## Pillars

| Pillar | Definition |
|---|---|
| Purpose | One sentence on why the brand exists beyond profit |
| Values | 4-5, each tied to an observable behavior |
| Target audience | Ideal customer profile and jobs to be done |
| Positioning | See template below |
| Differentiation | Concrete, not vague ("ships in 24 hours", not "fast") |

Positioning template: "For [customer] who [need], our [product] is a [category] that [benefit]. Unlike [competitor], we [differentiator] because [reasons]."

## Archetypes

Choose the archetype closest to the customer's personality and the brand's behavior, then use its tone words as a starting point for voice attributes.

| Archetype | Tone words |
|---|---|
| Creator | Innovative |
| Caregiver | Nurturing |
| Ruler | Authoritative, premium |
| Innocent | Simple, optimistic |
| Sage | Wise |
| Explorer | Adventurous |
| Outlaw | Rebellious |
| Magician | Visionary |
| Hero | Courageous |
| Lover | Passionate |
| Jester | Playful |
| Everyman | Down-to-earth |

Archetypes are a prompt for decisions, not a substitute for specific attributes with examples.

## Brand narrative

- Origin story elements: who founded it, why, obstacles overcome, vision, how it evolved.
- Customer-as-hero journey: hero (customer's need), problem (current workaround), inciting insight (a reframing that creates urgency), brand's role (guide, not hero), transformation (proof through cases and testimonials).
- Narrative arc: protagonist faces a challenge, stakes if nothing changes, proof, call to action placed inside the story.

## Guideline structure

Purpose and values; positioning one-liner; story summary; voice, tone, avoid/preferred words; visual identity sections (logo, color, type, imagery). Visual specs apply the same decisions across surfaces; keep the verbal and visual guides consistent.

## Pitfall

Do not publish statistics about storytelling or values-driven buying without a verifiable source.

# Narrative Structures for Non-Technical Audiences

## Core framework

1. Headline: one sentence carrying the essence. Test: understood in 10 seconds.
2. 3-5 key points in logical order (chronological, problem-solution, or importance-ranked).
3. Concrete proof per point.
4. One explicit CTA.

Per point, run the "so what?" test: does it answer why this audience should care?

## Choose a structure

| Situation | Structure | Beats |
|---|---|---|
| Major change, pivot | Hero's journey | Status quo, call to adventure, trials, victory, return with knowledge |
| Recommendation, proposal | Problem-Solution-Benefit | Problem with stakes, recommendation with rationale, quantified benefit |
| Launch, process change | Before-After-Bridge | Current painful state, improved state, the bridge |
| Executive, board, investor | Situation-Complication-Resolution | Context, what changed or what is at stake, path forward plus a named risk |

Generic six-beat arc: hook, context, rising action (data points), climax (key insight), resolution (recommendation), CTA.

## Techniques

- Humanize data: "42% churn" -> "We lose 12 customers every week". Use comparisons ("2x slower than competitors, 3x slower than last year"). One number per point.
- Technical to non-technical: translate jargon on first use; use analogies from the audience's domain; lead with business impact; answer "why does this matter?" explicitly.
- Change communication: name the loss, paint a concrete future state, show the path, address "what about me?" early.
- Crisis communication: facts first (what, when, impact); accountability without blame-shifting; concrete actions with a timeline; a commitment to when the next update arrives.

## Guardrails

- Front-load the conclusion.
- Show data sources and assumptions; state limitations.
- Avoid passive voice that hides agency.
- Keep the CTA specific.
- No fear-mongering or fake urgency.
- Self-review rubric: score clarity, relevance, proof and CTA specificity; revise until the average is at least 3.5 of 5.

## Data storytelling

Three pillars: data (evidence), narrative (meaning, causation, implication), visuals (clarity).

Headline formula: [specific number] + [business impact] + [actionable context]. "Q4 Sales Analysis" -> "Q4 Sales Beat Target by 23% - Here's Why".

### Report templates

| Type | Order |
|---|---|
| Problem-solution | Hook with a quantified loss; context vs benchmark; problem with segmented evidence; insight visual; solution list; expected impact with payback; one specific ask |
| Trend | Where we started; what changed (dated list of actions); before/after metric table; key insight (compound effect); going forward with a target |
| Comparison | Name the decision question; compare options on the same factors; weighted scoring matrix; recommendation with a first step; mitigation per risk |
| Executive summary slide | One insight sentence; two columns: the data per segment, and the implication with investment and expected ROI |
| One-page monthly review | Headline; KPI strip with deltas; what is working; what needs attention; root cause with a small chart; 3 recommendations; next month's focus |

Weighted scoring: score each option per factor, multiply by weight, sum. Check the arithmetic: weights 25/30/20/25 with scores 5/3/2/2 give 3.05, not a rounded guess.

### Visual storytelling devices

- Progressive reveal: one new layer per slide (headline first, then overlay, then segment breakdown).
- Contrast: side-by-side before/after panels, or a this-vs-that panel with the single difference emphasized.
- Annotation: mark events with an arrow, shade a period with a translucent span, draw the target as a dashed line labeled with its value.

### Uncertainty

State confidence and sample size ("with 95% confidence...", "the sample of 500 shows..."). Say correlation is not causation where relevant. Give ranges ($400K-$600K) or best/conservative pairs.

### Do and don't

| Do | Don't |
|---|---|
| Lead with the so-what | Dump data |
| Use three points or three comparisons | Put methodology before context |
| Let the data speak | Use jargon |
| Connect to audience goals | Show numbers without meaning |
| End with next steps | |

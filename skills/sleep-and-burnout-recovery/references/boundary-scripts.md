# Boundary Scripts

Adapt wording to the person's voice and workplace. Principle: state the constraint, offer a trade-off, keep it short, do not over-apologize or justify.

| Situation | Script |
|---|---|
| Declining extra work | "If I take this on, something else will suffer. Can we talk about what to deprioritize?" |
| Protecting off-hours | "I'm offline after [time]. I'll pick this up first thing tomorrow. If it's urgent, call me." |
| Declining a meeting | "I can't attend. Could you send summary notes or the decisions that need my input?" |
| Scope pushback | "I can do A or B this week, not both. Which matters more?" |
| Unrealistic deadline | "With the current load I can deliver this by [date]. To hit [earlier date], I'd need X moved or Y dropped." |
| Weekend/after-hours message | "Got it, I'll look at this Monday morning." (Reply on schedule, not instantly.) |
| Escalating to manager | "I'm running above capacity and it's affecting quality. Here are my current commitments; which should I drop or delay?" |

## Using the scripts

1. Pick one situation per week and rehearse it aloud or in writing.
2. Use the trade-off form: it turns "no" into a prioritization question the other side must answer.
3. Hold the boundary once; do not renegotiate in the same conversation under pressure.
4. Log each violation (date, request, response). This supports a later HR, EAP, or exit decision.
5. If the boundary is repeatedly ignored, feed that into the week 4-6 environment decision.
